## 매니저형 개발 워크플로

역할별 개발팀 구성·운영 또는 QA 피드백 루프를 사용자가 요청한 경우에
`.agents/skills/manager-dev-workflow/SKILL.md`와
`docs/dev-workflow/project.json`을 읽고 적용한다.
직접 수정하거나 매니저 스킬을 사용하지 말라는 요청에는 이 워크플로를 실행하지 않는다.
팀 사용법은 `.agents/skills/manager-dev-workflow/references/team-usage.md`를 참고한다. 대상 에이전트·기능과
필요한 역할·수정 경로·검증은 작업별로 정하며 특정 에이전트에 고정하지 않는다.
사용자가 작업 프로필을 지정하면 함께 읽고 실행 기록에 남긴다.
현재 메인 에이전트가 매니저이며 별도 서브에이전트에 실제 작업을 위임한다.
기본은 각 담당자의 작업 전 착수 카드 제시 → 사용자 답변 대기 → 승인 후 실행이다.
사용자 답변 없이 알림만 남기고 시작하지 않는다. 필요한 정보는 매니저를 통해
다른 담당자 또는 사용자에게 요청한다. QA 수정·재검증은 승인된 범위에서 최대 2회다.
프로젝트별 담당·소스·제외 범위는 프로필을 따르며, 기존 저장소 규칙도 유지한다.
개발팀의 승인과 제품 내부의 PM·업무 승인은 서로 대신할 수 없다.
