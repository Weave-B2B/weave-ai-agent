# 요청·범위 검토 테이블 데이터 딕셔너리

문서 v0.3 · 2026-10-28 · [전체 목록](../README.md)

변경 요청 식별·항목 구조화·범위 PM 판단에 해당하는 기존 테이블을 둔다. 에이전트 3는 앞 단계에서 조립한 입력을 통해 이 정보를 참조한다. 이 폴더는 업무 영역에 따른 분류이며, 특정 에이전트나 담당 팀의 소유권을 확정하는 것은 아니다.

| 테이블 | 역할 |
|---|---|
| [change_request](./change_request.md) | 변경 요청과 현재 검토 버전 |
| [request_item](./request_item.md) | 버전별 요청 항목 |
| [pm_judgment](./pm_judgment.md) | 앞 단계 범위 PM 판단 |

A1/A2의 저장 계약 전체를 새로 정의하지 않는다. 현재 문서는 에이전트 3 입력과 연결할 때 확인한 부분을 다룬다. 범위 PM 판단은 [협의안 작성 전 산정 PM 승인](../agent3/impact_approval.md)과 다른 데이터다. [출처](../references/README.md), [예시 값](../example_values.md) 참조.
