로컬 AI 화면 확인

요청 목록·원문·범위 검토는 합성 예시 데이터입니다. 영향 산정과 협의안은 기존 Agent 3 API에 연결합니다.

기본 실행기는 가상 AI 응답과 합성 단가를 사용합니다. 브라우저는 서버의 실제 모델 공급자 설정을 확인할 수 없습니다. API 호출 성공이 실제 모델 품질 검증을 뜻하지 않습니다.

로컬 PM 검토는 사용자 인증·상업 승인·고객 합의를 대신하지 않습니다. 고객 발송·청구는 이번 화면에 포함하지 않습니다.

서버 메모리의 세션은 재시작 시 사라집니다. 자세한 실행 방법은 docs/prototype/run.md를 확인하세요.
